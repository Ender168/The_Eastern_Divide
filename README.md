# The Eastern Divide

**A standalone Hearts of Iron IV scenario for two players.**

Take command of the Western or Eastern Side in an Eastern European campaign. Begin along a narrow front, then fight for key cities as the battle lines expand.

## Scenario

- Two opposing player countries, WEF and EEF, with neutral territories between and around them.
- 25 key cities for each side, highlighted on the map with 10 victory points.
- Standard and fast victory conditions, tracked by monthly checks and timed missions.
- Decisions for deploying fully equipped test armies when a side is human-controlled.
- A rebuilt railway and supply-hub network with reserve routes for both sides.
- English and Russian scenario and victory-condition localization.

## Installation

Copy the mod folder and descriptor.mod into your Hearts of Iron IV user mods directory, then enable **The Eastern Divide** in the launcher.

The current scenario descriptor targets game version 1.19.*. Check compatibility with your installed version before starting a multiplayer game.

## Status

This is an independently developed scenario with original project assets, using the vanilla Hearts of Iron IV map. The supply network has been checked statically for province ownership, land adjacency, and redundant routes. In-game supply behavior and multiplayer balance still require testing.
