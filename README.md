# The Eastern Divide

**A standalone Hearts of Iron IV scenario for two players.**

Take command of the Western or Eastern side in a focused Eastern European campaign. Begin along a narrow front, then fight for key cities as the battle lines expand.

## Scenario

- Two opposing player countries, WEF and EEF, with neutral territories between and around them.
- 25 key cities for each side, highlighted on the map with 10 victory points.
- Standard and fast victory conditions, tracked by hidden monthly checks and timed missions.
- Separate decisions for deploying fully equipped test armies when a country is human-controlled.
- A rebuilt railway and supply-hub network designed to support breakthroughs and withdrawals.
- Local supply hubs and level-four railway connections for both sides.

## Installation

Place the mod folder and descriptor.mod in your Hearts of Iron IV user mods directory, then enable The Eastern Divide in the launcher.

The scenario descriptor currently targets game version 1.19.*. Validate it against your installed game version before a multiplayer match.

## Status

This is an independently developed scenario with original project assets. The bundled map topology uses the vanilla Hearts of Iron IV map. The supply network has been checked statically for province ownership, land adjacency and redundant routes. In-game supply behavior and multiplayer balance still require playtesting.

## Languages

English and Russian scenario and victory-condition localization are included.
